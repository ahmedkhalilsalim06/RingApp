# Bilkent Bus RingApp

## Overview
Bilkent bus ring app is an app designed to make bus navigation easier for Bilkent students. it shows bus schedules, real time live locations and timings to eliminate confusion for Bilkent students when waiting for buses.

## How to run
To run this app, first clone the repo and open the app on android studio. The app can either be run on laptop using android studio (mobile simulation) or can be transferred to mobile using android studio as well. To transfer the app to mobile, the user must first enable USB debugging on their mobile. Then they need to connect the mobile to their laptop. After doing so, android studio will show their mobile as one of the options to run the app on. If the user now clicks run, it will download and run the app on their mobile. 

## Libraries and APIs
Google maps API
Google's firebase library

These dependencies are handled by Gradle of Android studio who automatically downloads and compile them to run the app.
